# Stitch Prompts

## Calibration Loop Console

```text
Design a desktop web app screen for Bad Unicorn, an AI candidate sourcing workspace for agency recruiters. Direction: Calibration Loop Console. The recruiter talks to an agent in natural language to turn a rough intake brief into a defensible shortlist. Keep chat central but make it operational, not a chatbot toy. Include: natural-language composer, conversation history, optimistic progress states for a non-streaming agent, brief quality meter, missing location/skills prompts, chips showing what changed after each answer, search criteria, generated search queries, and a 5-candidate shortlist with save/reject/compare states. Tone: cheeky Bad Unicorn brand, but professional and high-signal. Visual style: restrained recruiter workspace, dense and scan-friendly, neutral dark and light surfaces, one unicorn accent, signal green for progress. Avoid marketing hero sections, card mosaics, large decorative gradients, and novelty mascot UI.
```

## Evidence Board Workspace

```text
Design a desktop web app screen for Bad Unicorn, an AI candidate sourcing workspace for agency recruiters. Direction: Evidence Board Workspace. Prioritize side-by-side candidate comparison, transparent fit evidence, source confidence, evidence gaps, and recruiter decision notes. Include: natural-language agent rail, brief summary, comparison set of 2-3 candidates, each candidate with fit score, key strengths, concerns/gaps, LinkedIn/source confidence, skills/experience evidence, save/reject/compare states, and a compact query/criteria timeline. Tone: cheeky but professionally useful. Visual style: use the High-Signal Sourcing Lab system: dense, scan-friendly, neutral recruiter workspace with one unicorn purple accent and signal green. Avoid marketing hero sections, mascot UI, decorative gradients, and generic dashboard card mosaics.
```

## Search Strategy Cockpit

```text
Design a desktop web app screen for Bad Unicorn, an AI candidate sourcing workspace for agency recruiters. Direction: Search Strategy Cockpit. Focus on a power-user view where recruiters steer generated search strategy through natural language and structured controls. Include: natural-language agent rail, editable role criteria, generated Boolean/search query variants, exclusions, locations, seniority, source coverage, candidate pool size estimate, query performance notes, and a preview shortlist. Show how the agent broadens or tightens the search after recruiter feedback. Tone: cheeky but professional. Visual style: High-Signal Sourcing Lab system, dense operational workspace, neutral surfaces, restrained unicorn purple accent, signal green only for progress/quality. Avoid hero sections, decorative gradients, mascot UI, and generic analytics dashboards.
```
